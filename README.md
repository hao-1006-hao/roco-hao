# 命定勇者奖牌收集统计 · 洛克王国世界（roco-hao）

> 追踪洛克王国：世界「命定花种」活动的 **命定勇者奖牌** 收集进度。
> 玩法机制：官方每期推出若干「命定花种」精灵，用**任意精灵**单人通关其中一只，
> **通关成功后奖牌归【你所使用的精灵】**（而不是被通关的花种精灵）。
> 每只精灵通关过一次即获得一枚奖牌。数据保存在浏览器本地。

## 功能特性

### 精灵图鉴（面板 1）
- **全图鉴清单**：内置游戏全精灵图鉴 **596 只**（含一阶 / 二阶 / 三阶 / 首领进化各形态，18 系属性），
  每只精灵一张卡片，直接展示「有奖牌 / 无奖牌」
- **统计看板**：全图鉴总数、有奖牌 / 无奖牌数量、奖牌收集进度（环形进度图）
- **一键标记**：点击任意精灵卡片即可切换「有 / 无奖牌」（手动补录场景）
- **搜索 / 筛选 / 排序**：按名称 / 分类 / 备注搜索；按奖牌状态、18 系属性、阶段（一阶~首领进化）筛选；
  按图鉴编号 / 名称 / 奖牌日期排序
- **补充精灵**：新赛季 / 新活动上线的精灵，点「＋ 补充精灵」即可录入（名称、阶段、属性、赛季、备注）
- 精灵卡片分页渲染（200 只 / 批），超过可一键「加载全部」

### 奖牌与挑战记录（面板 2）★ 核心
- **已获得奖牌精灵 / 未获得奖牌精灵**：两块清单直接展示，一眼看出下次该用谁去打
- **记录挑战**：登记「用 X（使用的精灵）通关 Y（命定花种精灵）」的期数、日期、是否成功
  - 勾选「通关成功」时，**自动给使用的精灵 X 标记奖牌**（首次通关即获得）
  - 内置全图鉴精灵名 / 历期花种精灵名联想（datalist），输入更快速
- **智能撤销**：编辑 / 删除某条成功记录时，若该精灵没有其他成功记录，系统会自动撤销其
  「来自记录」的奖牌标记，保证数据一致
- **挑战记录按期数分组**：历史清晰可查，支持编辑、删除

### 小工具（面板 3）
- **命定花种活动倒计时**：当前期活动的剩余天数（`ACTIVITY_CONFIG` 每期更新）
- **分光水晶 ↔ 棱镜球换算**：1600 分光水晶 = 1 棱镜球，双向即时换算
- **奖牌分光水晶速算**：每枚奖牌可在图鉴领取 300 分光水晶，一键算出总奖励

### 通用能力
- **本地持久化**：所有数据保存在 `localStorage`，刷新 / 关页不丢失
- **数据备份**：一键导出 / 导入 JSON（合并或替换模式），换设备不丢进度
- **移动端适配**：响应式布局，支持添加到手机主屏幕（PWA Manifest）当轻量 App 用

## 关于初始数据

- `js/data.js` 的 `SPIRITS` 内置**全精灵图鉴 596 条**（名称 / 属性 / 阶段 / 种族分类 / 赛季），
  数据整理自玩家社区图鉴（biligame 洛克王国世界 Wiki），**如有出入请以游戏内实际为准**
- `FLOWER_PERIODS` 收录历期「命定花种」官方活动周期与目标精灵，`ACTIVITY_CONFIG` 为当前期活动配置
- 每期活动开始前，只需更新 `ACTIVITY_CONFIG`（活动时间 / 花种精灵）；游戏新增精灵时，
  在应用内点「＋ 补充精灵」录入即可（也可直接编辑 `js/data.js` 的 `SPIRITS`）

## 数据说明

- 所有记录仅保存在当前浏览器的 `localStorage` 中，不会上传任何服务器
- 清缓存 / 换设备前，请先在「数据管理」中导出 JSON 备份
- 导入 JSON 支持两种模式：**合并**（保留现有并覆盖同名）或 **替换**（清空后整体覆盖）
