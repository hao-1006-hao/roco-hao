# 命定勇者奖牌收集统计 · 洛克王国世界（roco-hao）

> 追踪洛克王国：世界「命定花种」限时活动的 **命定勇者奖牌** 收集进度，
> 并记录**每一期挑战时使用的精灵**，统计哪些精灵已经用过、哪些还没用过，
> 避免重复使用同一只精灵而错失奖牌奖励。数据保存在浏览器本地。

## 功能特性

### 奖牌收集（面板 1）
- **统计看板**：收录精灵总数、已获得 / 待挑战数量、完成进度（环形进度图）
- **按期数统计**：每一期命定花种活动的收集率进度条，点击可直接筛选该期精灵
- **精灵卡片**：金色奖牌图标 + 状态徽章（已获得 / 未获得），点击卡片一键标记
- **添加 / 编辑 / 删除**：随时把新上线的命定花种精灵加入清单
- **搜索 / 筛选 / 排序**：按名称、期数、笔记搜索，按状态、期数筛选排序

### 使用记录与统计（面板 2）★ 核心功能
- **记录使用**：记录每一期挑战命定花种时派出的精灵、挑战对象、日期、是否成功
  - 勾选「挑战成功」时，**自动同步**把对应命定花种精灵的奖牌标记为已获得
  - 内置精灵名 / 花种名联想（datalist），记录更快速
- **已使用 / 未使用统计**：精灵库中哪些精灵用过、哪些还没用过一目了然
  - 精灵库 = 手动维护的候选精灵 + 使用记录中出现的精灵（自动计入）
- **未使用精灵清单**：直接展示还没派上用场的精灵，方便规划下一期用谁
- **使用记录按期数分组**：每期用过的精灵历史清晰可查，支持编辑、删除

### 小工具（面板 3）
- **命定花种活动倒计时**：当前期活动的剩余天数（数据在 `js/data.js` 的 `ACTIVITY_CONFIG` 中每期更新）
- **分光水晶 ↔ 棱镜球换算**：1600 分光水晶 = 1 棱镜球，双向即时换算
- **奖牌分光水晶速算**：每枚命定勇者奖牌可在图鉴领取 300 分光水晶，一键算出总奖励

### 通用能力
- **本地持久化**：所有数据保存在 `localStorage`，刷新 / 关页不丢失
- **数据备份**：一键导出 / 导入 JSON（合并或替换模式），换设备不丢进度
- **移动端适配**：响应式布局，支持添加到手机主屏幕（PWA Manifest）当轻量 App 用

## 快速开始

直接用浏览器打开 `index.html` 即可使用，无需安装、无需后端。

```bash
# 本地预览
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 关于初始数据

- `js/data.js` 内置了 2026 年 3 月至今已出现的 29 只命定花种精灵，期数按活动上线月份整理，
  部分信息来自玩家社区，**期数 / 难度 / 属性均可直接在应用内编辑修正**
- `SEED_ROSTER` 是攻略中常用的挑战精灵示例库（罗隐、画间沉铁兽等），仅供演示，
  请通过「管理精灵库」按自己的实际精灵调整
- 游戏每期新增的花种精灵，点「＋ 添加精灵」即可录入；使用记录点「＋ 记录使用」即可登记

## 数据说明

- 所有记录仅保存在当前浏览器的 `localStorage` 中，不会上传任何服务器
- 清缓存 / 换设备前，请先在「数据管理」中导出 JSON 备份
- 导入 JSON 支持两种模式：**合并**（保留现有并覆盖同名）或 **替换**（清空后整体覆盖）

## 部署到 GitHub Pages（可选）

把本仓库推送后，在仓库 Settings → Pages 中把部署分支设为 `main` / 根目录，
即可获得在线访问地址，手机上打开后还能"添加到主屏幕"当作 App 用。
